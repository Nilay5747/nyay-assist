 Nyay Assist

Nyay Assist is a web-based legal information portal developed to help users quickly access legal information through keyword-based law search.

## Features

* User Registration and Login
* Keyword-Based Law Search
* Legal Information Database
* Constitution Access
* Legal Resource Links
* Responsive User Interface

 Technologies Used

## Frontend

* HTML
* CSS
* JavaScript

## Backend

* Python

## Database

* SQLite

### Project Objective

The objective of Nyay Assist is to provide users with easy access to legal information and resources through a simple web interface.

### Future Improvements

* AI-powered legal query assistance
* Expanded legal database
* Advanced search capabilities
* Document upload and analysis
